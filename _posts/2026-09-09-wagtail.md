# September 2026: Wagtail, the Content Management System (CMS)

A content management system is software that lets you build and manage digital content 
on a website without needing to write code.  The best-known example is WordPress.

[Wagtail](https://wagtail.org/) is a popular CMS, built on Django (which is, in turn, 
the best-known Python web application platform).  It's built to produce a high-quality 
CMS application with minimal effort.

So let's put it to the test!  We'll play with the tutorial together and see what a 
DDL CMS might look like.  Perhaps we'll even deploy it!
