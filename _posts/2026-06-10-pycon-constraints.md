# June 2026: Pycon, Constrained Problems, and remote_exec 

Pycon US 2026 is over, so let's have a recap!  Including:

## Python 3.14 remote_exec

Have you seen a Western in which the hero gallops up alongside a speeding 
train and leaps aboard?  Wouldn't you like to do that in Python?

Python 3.14 introduces [remote_exec](https://runebook.dev/en/docs/python/library/sys/sys.remote_exec), enabling you to attach to, run code in, and debug 
a Python program running *in another process* without any preparation - 
perfect to figure out what's going on in a long-running program without
restarting it.
